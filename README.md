# Lab 9 - Book Finder

## Description
Book Finder is a web application that allows users to
search for books by title or author using the Open Library API.

## Features
- Search for books by title or author
- Display book covers, titles, and authors
- Show and hide additional book details
- Handle searches with no results
- Save books to a personal bookshelf
- Remove books from the bookshelf
- Keep saved books after refreshing the page
- Responsive design for mobile devices

## Technologies Used
- HTML
- CSS
- JavaScript
- Open Library API
- Browser Local Storage

## Resources
- Open Library API: https://openlibrary.org/developers/api
- MDN Web Docs: https://developer.mozilla.org/
